# Laboratorio HTML, CSS y JS - Contador

## Descripción
Proyecto básico de un contador usando JavaScript que permite incrementar y decrementar un valor.

## Funcionalidades
- Mostrar contador en pantalla
- Botón para incrementar
- Botón para decrementar
- Cambio de color cuando el contador llega a 10

## Tecnologías
- HTML
- CSS
- JavaScript
